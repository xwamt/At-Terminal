# AT Terminal 0.3.1 Release Notes

Version 0.3.1 brings significant security, performance, and reliability improvements across MCP agent integration, SSH connection management, SFTP file synchronization, and terminal streaming.

## Highlights & New Features

### 1. Remote Command Execution Policy & Safety Gate
- **Smart Pipeline Auto-Approval**: Safe, read-only commands and pipeline chains (e.g. `top -bn1`, `cat /var/log/nginx/access.log | grep 500`, `df -h && uptime`) are automatically approved without modal confirmation interrupts.
- **AST-Level Blocklist & Gate**: Stateful commands (`rm`, `mv`, `systemctl`, `docker`), code interpreters (`sh`, `bash`, `python`, `awk`, `sed`, `sudo`), and unparseable shell constructs (`$(...)`, backticks, output redirection `>`) require explicit user confirmation.
- **Destructive Command Highlighting**: Dangerous operations (`rm -rf /`, `mkfs`, `dd`) trigger high-risk warning banners in confirmation modals.

### 2. SSH Connection Pooling & Lifecycle
- **Connection Reuse**: Reuses active SSH connections per server for agent command executions instead of performing a full SSH handshake on every invocation.
- **Automatic Resource Cleanup**: Cleanly disposes of pooled agent SSH sessions upon extension deactivation.
- **Mandatory Host Key Verification**: Enforces strict host key verification policies by default to prevent MITM attacks.

### 3. SFTP Bounded Payloads & Directory TTL Authorization
- **Bounded Directory Listing**: `sftp_list_directory` enforces a 500-entry default limit (hard cap 5000) and returns `truncated` and `total` counters to protect LLM context windows from token explosion.
- **Directory-Scoped Authorization with TTL**: SFTP write approvals are scoped to `(serverId, parentDirectory)` with a 15-minute TTL rather than granting server-wide write access.
- **Privilege Escalation Prevention**: Prevents agent SFTP writes from escalating through `sudo`.
- **Sensitive Path Double-Check**: Operations targeting system directories (`/etc`, `/usr`, `/bin`, `/boot`, `/root`, `/var/spool/cron`) require dual-stage confirmation and are never cached.
- **Remote Edit Conflict Detection**: Prevents discarding or overwriting remote edits that have not been synchronized.

### 4. Terminal Performance & Build Optimization
- **Coalesced Base64 Terminal Output**: Terminal output frames are batched (8ms / 64KB) and transmitted via coalesced Base64 encoding.
- **Linear-Time Semantic Highlighting**: Replaced $O(m^2)$ regex matching with linear-time match folding.
- **True Base-Variant Tree-Shaking**: Agentless base variant builds drop `@at-series/mcp-hub` completely, reducing extension bundle size by over 70%.
- **Non-Blocking Toast Notifications**: Replaced blocking modal/information toasts with asynchronous non-blocking dispatch.
