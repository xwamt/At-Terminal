# AT Terminal 0.3.5 Release Notes

Version 0.3.5 delivers a major performance, capability, and developer-experience update. It introduces full directory transfer and conflict-safe SFTP workflows, WebGL terminal acceleration with output flow control, expanded agent MCP tools with background pooling and audit logging, SSH passphrase and ~/.ssh/config import support, robust host-key error recovery, and comprehensive packaging and regression optimizations.

## Highlights & New Features

### 1. SSH Authentication, Configuration & Port Forwarding (Slice A)
- **Hardened SSH Authentication**: Added structured authentication status reporting and support for encrypted private keys with passphrase prompts (stored securely in VS Code SecretStorage) and Keyboard-Interactive auth.
- **SSH Config Import with Picker Fallback**: Users can directly import servers from `~/.ssh/config`. If the standard path cannot be read due to permissions or sandboxing, a native file picker is automatically presented.
- **Local Port Forwarding**: Added support for configuring and managing local port forwarding tunnels bound to active SSH sessions.

### 2. Advanced SFTP Runtime, Directory Transfers & Listing Cache (Slice B)
- **Directory-Level Transfers**: Added recursive directory upload and download pipelines with concurrency management and progress reporting.
- **Conflict-Safe Drag & Drop**: Drag-and-drop file uploads detect destination name collisions and prompt the user for overwrite confirmation.
- **Listing Cache with Targeted Invalidation**: Implemented a responsive SFTP directory listing cache with TTL and automatic invalidation on file modifications to minimize remote roundtrips.

### 3. High-Performance Terminal, WebGL & Stream Flow Control (Slice C)
- **WebGL Accelerated Rendering**: Integrated `@xterm/addon-webgl` for hardware-accelerated terminal rendering, with seamless canvas fallback on unsupported environments.
- **Output Flow Control & Flood Protection**: Integrated `TerminalOutputBatcher` to safeguard against massive stdout bursts or binary stream floods without hanging the UI.
- **Terminal Search, Reconnect & Session Logging**: Integrated find-in-terminal bar, UX-friendly reconnect countdown for dropped connections, customizable session logging to disk, and multi-encoding character support.

### 4. Agent MCP Tools, Background SFTP Pooling & Audit Logging (Slice D)
- **Background SFTP Session Pooling**: Agents can perform remote file operations using managed background SFTP connections with idle TTL and automatic teardown hooks.
- **Expanded MCP Toolset**: Added `sftp_rename` and `sftp_delete` tools (with mandatory delete confirmation), plus `offset` and `limit` parameters on read and list tools to allow agents to efficiently inspect large files in chunks.
- **Agent Audit Log**: All MCP agent actions, confirmations, and file operations are recorded into a dedicated VS Code OutputChannel and persisted to structured `agent-audit.jsonl` files.
- **MCP Hub Fast-Path Synchronization**: Optimized `@at-series/mcp-hub` catalog synchronization by skipping SHA-256 hashing when file size, version, and modification timestamp match.
- **Execution Safeguards**: 120-second command confirmation dialog timeout, localized labels, and stderr capture even when commands encounter timeouts.

### 5. UX Polish, Host Key Recovery & Full Localization (Slice E)
- **Host Key Mismatch Recovery**: Provides interactive guided recovery dialogs when host keys change or fail verification.
- **ViewsWelcome & Empty State Polish**: Enhanced guidance when no servers are configured or when views are empty.
- **Comprehensive Chinese (zh-CN) Localization**: Full translation coverage across all views, forms, notifications, and commands (`package.nls.zh-cn.json` and `l10n/bundle.l10n.zh-cn.json`).

### 6. Architecture, Regression Fixes & Package Optimization
- **SFTP Tree View Synchronization**: Bound the SFTP view source of truth strictly to the terminal registry, ensuring the view never gets stuck on stale "No active SSH terminal" placeholders.
- **Server Tree Instant Registration**: Server tree providers register immediately during extension activation so assets appear instantly without requiring an extension reload.
- **Legacy Asset Migration**: Automatic schema migration for legacy server definitions and encrypted asset packages.
- **VSIX Packaging Optimization**: Excluded documentation images (`docs/images`) from `.vsix` bundles to keep extension installation sizes minimal.
- **Dependency Updates**: Bumped `@at-series/mcp-hub` to `^0.3.3` and `@at-series/command-policy` to `0.1.1`.
