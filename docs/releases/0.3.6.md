# AT Terminal 0.3.6 更新说明（Release Notes）

> **Version**: `0.3.6`  
> **Release Date**: 2026-11-23  
> **Git Tag**: `v0.3.6`  
> **Branch**: `main`

版本 **0.3.6** 完成 VS Code / Cursor / Kiro 扩展优化计划（OPT-01 ~ OPT-13），重点提升扩展宿主稳定性、SSH/SFTP 连接资源复用、MCP 取消能力、SFTP 编辑安全性以及日常操作体验。

---

## 🌟 核心更新

### 1. 扩展宿主稳定性与资源释放

- **全部 SSH 建连点补齐常驻监听**：为 `SshSession`、跳板机 `jumpClient`、`SftpSession` 和端口转发连接补齐常驻 `error` / `close` / `end` 监听，避免 ssh2 二次 `error` 事件导致 Extension Host 崩溃。
- **SFTP 死连接自动恢复**：`SftpSession` 在连接断开后立即失效；`SftpManager` 与 `SftpAgentService` 会在下一次请求时自动重建会话。
- **空闲断开更准确**：终端远程输出也计入活动时间，`tail -f`、远程编译、数据库备份等持续输出任务不会因 `idleDisconnectMinutes` 被误杀。
- **终端断开释放 Agent SFTP**：终端因超时、网络中断或主动断开而进入 `connected: false` 时，立即释放该终端绑定的 Agent SFTP 连接。
- **服务器配置联动清理**：编辑或删除服务器时，同步驱逐 `RemoteCommandExecutor` 连接池、跳板机连接缓存，并停止该服务器上活跃的本地端口转发。

### 2. SSH 与 Agent 连接池

- **跳板机连接池**：同一跳板机的并发终端、SFTP 和 MCP 请求共享一条已认证 `jumpClient`；60 秒空闲回收，跳板机主动 `close` / `end` 时立即驱逐缓存。
- **多级链式跳板**：支持 A → B → C 多级跳板，最大 4 级，并增加环路检测（如 A → B → A 会明确报错）。
- **Agent SSH 连接池复用**：`run_remote_command` 与后台 SFTP 工具共享同一客户端，单次排查只进行一次 SSH 握手与认证。

### 3. MCP 取消链路与输出处理

- **HTTP 中断透传 `AbortSignal`**：MCP 客户端点击 Stop 或断开 HTTP 请求时，取消信号贯穿 `BridgeServer` → `AgentToolService` → `RemoteCommandExecutor`。
- **远端进程终止**：取消或超时时先发送 `TERM` 再关闭 channel，降低远端进程残留风险。
- **UTF-8 截断安全**：输出达到字节上限时按 UTF-8 字符边界回退，不再出现末尾 `�` 乱码。

### 4. SFTP 安全与编辑能力

- **`sudo -n` 临时文件加固**：`/tmp` 下用于提权写入/上传的临时文件强制 `0o600`，避免写入窗口内被其他本机用户读取。
- **读操作超时**：`listDirectory`、`statPath`、`readFile` 与 `realpath('.')` 统一 30 秒超时，SFTP 通道挂起不会永久卡住 MCP 调用。
- **`~` 家目录展开**：支持 `~`、`~/...` 路径。
- **`sftp_edit_file` 局部编辑**：新增基于 `oldText` / `newText` 的精准替换，支持 `replaceAll`；`expectedSize` / `expectedModifiedAt` 提供乐观锁，写入前再次校验版本。
- **`sftp_write_file` 能力增强**：支持 `localPath` 宿主本地文件流式上传（不经过模型上下文），并拒绝 `~/.ssh` 等敏感本地凭据路径。
- **预览/编辑保护**：预览默认 20 MiB、编辑默认 50 MiB 软上限；大文件或 `.zip` / `.tar.gz` 等二进制文件打开前提示确认，取消时不会下载。

### 5. 审计、拖拽与端口转发体验

- **审计日志优化**：`AgentAuditLog` 缓存目录初始化，避免每次 `record()` 重复 `mkdir`；`agent-audit.jsonl` 超过 10 MiB 自动轮转为 `.1`。
- **拖拽上传增强**：支持拖入本地文件夹递归上传；上传完成后自动刷新 SFTP 树。
- **端口转发多实例**：单台服务器可同时转发多个端口（如 MySQL 3306 + Redis 6379）；新增 `$(plug) AT Forwards: N` 状态栏入口，可单独停止或复制地址；SSH 断开自动清理。

### 6. 工程治理

- **`extension.ts` 模块化拆分**：命令按领域拆分为 `serverCommands`、`sftpCommands`、`portForwardCommands`、`mcpCommands`，`extension.ts` 保持为 249 行的组合根（小于 250 行目标）。
- **历史 `.vsix` 清理**：根目录历史制品统一移入 `dist/releases/`，不再与源码混放。
