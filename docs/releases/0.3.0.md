# AT Terminal 0.3.0 Release Notes

## Summary

Version 0.3.0 splits the shared AT Series MCP Hub out of this repository into the published npm package [`@at-series/mcp-hub`](https://www.npmjs.com/package/@at-series/mcp-hub). AT Terminal MCP now consumes Hub from the public registry, copies the hub runtime into the VSIX at package time, and no longer requires a local Hub checkout or `file:` dependency.

## Highlights

- **MCP Hub split**: depend on `@at-series/mcp-hub` `^0.1.1` from npm instead of a local worktree link.
- **Packaging**: `scripts/copy-hub.mjs` copies `hub.js` and writes `hub-version.json` for elect/sync.
- **Docs**: README documents the split boundary and install/build flow for 0.3.0.
