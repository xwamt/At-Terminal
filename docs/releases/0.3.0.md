# AT Terminal 0.3.0 Release Notes

## Summary

Version 0.3.0 migrates AT Terminal MCP to the shared **AT Series MCP Hub** (Protocol v1). The hub runtime lives in the published npm package [`@at-series/mcp-hub`](https://www.npmjs.com/package/@at-series/mcp-hub); this extension publishes bridges, elects packaged `hub.js`, and installs a single **AT Series** MCP entry. Per-plugin `mcp-server.js` and VS Code `languageModelTools` are removed from the product packaging.

## Highlights

- **AT Series Hub**: one IDE MCP entry (`node ~/.at-series/mcp/hub.js`) shared across AT-family plugins.
- **Hub package split**: depend on `@at-series/mcp-hub` `^0.1.1` from the public npm registry — no local Hub checkout or `file:` link required.
- **Protocol v1 Bridge**: Bridge HTTP exposes `health` / `tools` / `invoke`, with registry publish under `~/.at-series/bridges/<hostApp>/`.
- **Safer defaults**: installer `autoApprove` covers hub builtins and `read`-risk tools only (`exec` / `write` stay out of auto-approve).

## Added

- Dependency on published [`@at-series/mcp-hub`](https://www.npmjs.com/package/@at-series/mcp-hub) (`^0.1.1`).
- Packaged hub sync: MCP builds copy `dist/hub.js` plus `dist/hub-version.json`; activation elects the bundle into `~/.at-series/mcp/`.
- Bridge registry publish for AT Series Protocol v1 (`health` / `tools` / `invoke`).
- Host-app detection for registry paths and MCP env (`AT_SERIES` / IDE-specific host apps).
- Centralized MCP tool catalog with risk classification (`read` / `exec` / `write`).
- Install / repair / uninstall commands for the shared **AT Series** MCP config (migrates away legacy per-plugin `AT Terminal` entries).
- Docs: README hub-split section, [ADR-004](../decisions/ADR-004-at-series-mcp-hub.md), [ADR-005](../decisions/ADR-005-at-series-hub-adaptation.md).

## Changed / Removed

- **Breaking (MCP clients):** configure **AT Series** → `node ~/.at-series/mcp/hub.js`. Do not point IDEs at a per-plugin `mcp-server.js`.
- Removes product `languageModelTools` contributions.
- Stops building and shipping `dist/mcp-server.js` as the IDE MCP entry.
- MCP packaging no longer depends on a local Hub worktree; `npm install` pulls the published package.

## Migration

1. Upgrade to `at-terminal-mcp-0.3.0.vsix` (or newer).
2. Run **Install/Repair AT Series MCP Config**, or let activation ensure the AT Series entry.
3. In Cursor / Continue / Kiro / other MCP clients, confirm a single **AT Series** server and remove any leftover `AT Terminal` / `mcp-server.js` entries.
4. Background remote commands still require per-server **Trust agent remote commands** and **Allow background connections** (unchanged from 0.2.17).
