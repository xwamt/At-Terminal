# AT Terminal 0.3.3 Release Notes

Version 0.3.3 delivers important usability, safety, and operational enhancements to the SSH server form configuration workflow and the MCP remote command confirmation policy, providing seamless multi-language server credential editing and smarter read-only command auto-approvals for AI agents.

## Highlights & New Features

### 1. SSH Server Form Password Preservation & Edit Mode Decoupling
- **Multi-Language Password Retention**: Decoupled the server form's password validation from language-dependent DOM text inspection. When editing an existing SSH server in any locale (English, Simplified Chinese, etc.), leaving the password blank safely preserves the existing password in VS Code SecretStorage.
- **Explicit Form Mode Lifecycle**: Added `data-mode="create|edit"` attributes to the server form to cleanly distinguish add and edit operations on the frontend while enforcing password requirements for new password-authenticated servers.
- **Inline Validation & Localized Alerts**: Added localized webview validation feedback (`errorPasswordRequired`) ensuring clear guidance when passwords are required on new server creation.

### 2. Remote Command Safety Gate & Safe Redirection Auto-Approval
- **Safe Stream Redirection Recognition**: Extended the remote command policy (`remoteCommandPolicy.ts`) to recognize safe output-discarding and descriptor-duplicating redirections (e.g. `2>/dev/null`, `>/dev/null 2>&1`, `&>/dev/null`, `1>&2`, `2>&-`). On trusted servers (`agentCommandAutoApprove === true`), diagnostic commands utilizing error suppression run automatically without triggering false-positive confirmation dialogs.
- **Dangerous Redirection Containment**: Any file-writing or file-reading redirections (e.g. `> /etc/hosts`, `>> file`, `2> /tmp/err`, `< /etc/shadow`) remain strictly gated and require explicit confirmation.
- **Standard System Binary Path Resolution**: Read-only commands invoked via full standard system paths (e.g. `/bin/ls`, `/usr/bin/cat`, `/usr/bin/uptime`, `/bin/df`) are mapped to their basename and evaluated against the blocklist, allowing trusted system tool invocations while continuing to gate custom/external scripts (`./deploy.sh`, `/tmp/payload`).
- **Compound Shell Control Flow Keyword Support**: Enhanced pipeline and multi-command parsing to recognize and skip shell control keywords (`do`, `then`, `else`, `elif`, `if`, `while`, `until`, `for`, `case`, `done`, `fi`, `!`). Diagnostic compound commands (e.g. `for p in ...; do cat $p 2>/dev/null; done`) execute unhindered, while dangerous commands within loops (`do rm $p`) remain 100% intercepted.
- **Lookup Command Rule Addition**: Added argument-level inspection for `command -v` and `command -V` to allow path resolution without prompts, while gating arbitrary command execution wrappers.

### 3. Quality Assurance & Regression Verification
- **Policy Test Suite Expansion**: Added comprehensive test cases covering complex shell loops, error suppression streams, standard binary paths, command lookup flags, and destructive loop interception across 184 test assertions.
- **Markup & Webview Tests**: Added automated tests verifying `data-mode` attributes, edit mode credential retention, and locale-agnostic form validation behavior.
