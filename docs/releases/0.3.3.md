# AT Terminal 0.3.3 Release Notes

Version 0.3.3 delivers important usability, safety, and operational enhancements to the SSH server form configuration workflow and the MCP remote command confirmation policy, providing seamless multi-language server credential editing, a three-level agent trust dropdown, and smarter inspection-command auto-approvals for AI agents.

## Highlights & New Features

### 1. SSH Server Form Password Preservation & Edit Mode Decoupling
- **Multi-Language Password Retention**: Decoupled the server form's password validation from language-dependent DOM text inspection. When editing an existing SSH server in any locale (English, Simplified Chinese, etc.), leaving the password blank safely preserves the existing password in VS Code SecretStorage.
- **Explicit Form Mode Lifecycle**: Added `data-mode="create|edit"` attributes to the server form to cleanly distinguish add and edit operations on the frontend while enforcing password requirements for new password-authenticated servers.
- **Inline Validation & Localized Alerts**: Added localized webview validation feedback (`errorPasswordRequired`) ensuring clear guidance when passwords are required on new server creation.

### 2. Three-Level Agent Trust & Quote-Aware Command Confirmation
- **Trust dropdown**: Replaces the boolean “Trust agent remote commands” checkbox with three levels. Stored value is `agentCommandTrust` (`none` / `policy` / `full`); existing `agentCommandAutoApprove: true` servers migrate to **Limited trust**.
  - **Untrusted**: every `run_remote_command` asks for confirmation. The background-connection control is hidden.
  - **Limited trust**: today’s blocklist / quote-aware lexer. Background connection is shown and defaults to off when switching to this level.
  - **Full trust**: remote commands and SFTP writes run without confirmation, including sensitive paths. Background connection is shown and defaults to on when switching to this level.
- Opening an existing server restores the saved background-connection checkbox. SSH host-key trust and asset-package passwords are never skipped.
- **Quote-aware lexer**: `|`, `>`, and `\` inside `'...'` / `"..."` are no longer treated as shell operators. `grep -E 'error|fail'`, `awk 'NR>1'`, and `CPU\(s\)` run without a prompt under Limited trust. Unquoted `$()`, backticks, and file redirects still confirm. `$()` inside double quotes still confirms.
- **Read subcommands**: `docker ps` / `docker compose ps` / `kubectl get` / `virsh list` auto-approve; `docker exec` / `docker run` / `kubectl delete` / `virsh destroy` still confirm.
- **Read flags**: `iptables -L` / `-nvL`, `firewall-cmd --state`, `ufw status`, and `systemctl --failed` auto-approve; `iptables -F` / `-A` still confirm.
- **awk / sed filters**: pipeline filters auto-approve; `sed -i` and `awk 'BEGIN{system(...)}'` still confirm.
- Wrappers (`sudo`, `timeout`, `sh`, `python`, `xargs`) remain always-confirm under Limited trust.
- **Safe Stream Redirection Recognition**: Safe output-discarding and descriptor-duplicating redirections (e.g. `2>/dev/null`, `>/dev/null 2>&1`, `&>/dev/null`, `1>&2`, `2>&-`) do not prompt. File-writing or file-reading redirections (e.g. `> /etc/hosts`, `>> file`, `2> /tmp/err`, `< /etc/shadow`) still require confirmation.
- **Standard System Binary Path Resolution**: Read-only commands invoked via full standard system paths (e.g. `/bin/ls`, `/usr/bin/cat`, `/usr/bin/uptime`, `/bin/df`) are mapped to their basename and evaluated against the blocklist.
- **Compound Shell Control Flow Keyword Support**: Pipeline and multi-command parsing skips shell control keywords (`do`, `then`, `else`, `elif`, `if`, `while`, `until`, `for`, `case`, `done`, `fi`, `!`). Diagnostic compound commands execute unhindered; dangerous commands within loops (`do rm $p`) remain intercepted.
- **Lookup Command Rule Addition**: Argument-level inspection for `command -v` and `command -V` allows path resolution without prompts, while gating arbitrary command execution wrappers.

### 3. Quality Assurance & Regression Verification
- **Policy Test Suite Expansion**: Quote-aware lexer, polymorphic docker/iptables/systemctl/awk/sed rules, eleven host-inspection auto-approve cases, three-level trust gates, and SFTP skip-on-full-trust coverage.
- **Markup & Webview Tests**: `data-mode` attributes, edit mode credential retention, locale-agnostic form validation, and the trust dropdown plus background-connection defaults.
