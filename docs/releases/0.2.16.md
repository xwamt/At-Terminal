# AT Terminal 0.2.16 Release Notes

## Summary

Version 0.2.16 improves SFTP transfer/sync progress notifications, shortens long remote-command confirmation dialogs, hardens MCP bridge client retries, stabilizes terminal panel layout/fit, and expands the AT Terminal MCP operations skill with progressive-disclosure references.

## Added

- Progressive-disclosure AT Terminal MCP skill references for setup, safe operations, incident response, Linux host, network/DNS/TLS, Docker Compose, Kubernetes, web proxy, databases, observability, deployments/rollbacks, backup/DR, security incidents, storage, systemd, and workspace troubleshooting.
- Shared remote-command confirmation preview helper with truncation (first of 20 lines or 800 characters) and an explicit truncated marker.
- Failure notification duration constant for longer-lived error toasts.

## Fixed / Improved

- Keeps upload/download progress notifications open until the transfer job completes instead of dismissing early.
- Keeps remote-edit sync progress notifications open until the upload finishes (status bar and progress notification).
- Truncates only the command body in `run_remote_command` confirmation modals so long commands no longer overflow the screen; destructive warnings remain fully visible.
- Retries MCP bridge discovery and HTTP calls up to three times when the bridge file is missing, the connection fails, or a 401 indicates a stale bridge token.
- Stabilizes terminal webview fit/resize: absolute layout surface, requestAnimationFrame coalescing, skip no-op size changes, and prevent xterm shrink-lock from content width.
