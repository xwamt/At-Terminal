# AT Terminal 0.3.2 Release Notes

Version 0.3.2 introduces full-spectrum internationalization (i18n / l10n) support across the extension manifest, server configuration webviews, SFTP file workflows, terminal panels, and status notifications, providing seamless bilingual (English / Simplified Chinese) localization.

## Highlights & New Features

### 1. VS Code Native Internationalization & Localization (l10n)
- **Standard `vscode.l10n` Infrastructure**: Implemented lightweight `t()` localization helper leveraging VS Code's official localization runtime with fallback resilience.
- **Bilingual Manifest Localization**: Migrated all command titles, view container descriptions, configuration settings, and context menu items to NLS localization tokens (`%...%`) backed by `package.nls.json` and `package.nls.zh-cn.json`.
- **Runtime Localization Bundles**: Added runtime localization bundle `l10n/bundle.l10n.zh-cn.json` supporting dynamic language switching without requiring extension reloads.

### 2. Webview & Server Form Localization
- **Server Form Webview (`ServerFormPanel`)**: Fully localized all server configuration fields, authentication mode pickers (password, private key, agent), jump server selectors, port forwarding options, and real-time input validation errors.
- **Interactive Connection Testing**: Localized connection test status feedback, loading spinners, credential alerts, and result banners.
- **Webview Localization Contract**: Standardized webview localization payload injection on panel creation and state restoration.

### 3. SFTP Lifecycle & Terminal Interaction Localization
- **SFTP Operations**: Localized all prompts, confirmation dialogs, progress notifications, and failure alerts across upload, download, preview, edit, delete, rename, and new directory creation.
- **Conflict & Safe Guard Alerts**: Localized remote edit synchronization notices, uncommitted changes warnings, and binary file protection dialogs.
- **Asset Import / Export & SSH Tester**: Full bilingual support for batch server asset import, JSON schema validation, asset backup export, and SSH host key verification prompts.
- **Terminal Panels**: Localized terminal lifecycle notifications, connection indicators, and reconnect toasts.

### 4. Build, Packaging & Quality Assurance
- **Variant Packaging Integration**: Updated `scripts/package-variant.mjs` to bundle NLS files into both standard (`at-terminal`) and MCP (`at-terminal-mcp`) VSIX distribution archives.
- **Automated Localization Testing**: Added comprehensive i18n test suites (`test/i18n/nls.test.ts`, `test/i18n/t.test.ts`) validating key completeness, format specifier replacement, and fallback fidelity across all 633 unit and integration tests.
