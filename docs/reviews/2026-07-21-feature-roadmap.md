# AT Terminal 功能路线图（基于 0.2.16 审阅）

- **生成日期**: 2026-07-21
- **来源**: 对 `main` @ 0.2.16 的完整代码审阅

## 指导原则

1. 对任何面向 Agent 的写 / 执行路径，**安全优先于便利**。
2. 保持 **一套代码、两个安装包**（基础版 vs MCP）。
3. **凭证与信任确认 UI 留在扩展宿主**；MCP 只做瘦客户端。
4. 优先做让运维 Agent「可靠好用」的能力，而不是花哨终端外观。

## 当前 — 0.2.17 安全补丁

| 事项 | 类型 | 原因 |
| --- | --- | --- |
| 在激活装配中恢复真实的 `SftpWriteAuthorizer` | 缺陷修复 | 当前生产装配自动批准 SFTP 写入 |
| 所有 SSH / SFTP 连接路径传入主机密钥校验器 | 缺陷修复 | SFTP 路径可能跳过信任检查 |
| Bridge 请求 schema + body 上限 | 加固 | 防畸形载荷 / 本机不可信调用方 |
| 多 bridge 发现方案预研 | 加固 | 多窗口 IDE 会覆盖单一发现文件 |
| MCP server 版本与扩展版本对齐 | 打磨 | 避免支持沟通混乱 |
| 在 package 配置中声明 `sshManager.idleDisconnectMinutes` | 打磨 | 行为已存在但用户不可见 |
| 为装配安全不变量增加回归测试 | 测试 | 防止再次被静默绕过 |

## 下一步 — 连接与运维体验

| 功能 | 用户价值 | 备注 |
| --- | --- | --- |
| 从 `~/.ssh/config` 导入 | 加快上手 | 映射 Host / User / Port / IdentityFile / ProxyJump |
| 私钥 passphrase 支持 | 适配真实企业密钥 | 口令进 SecretStorage |
| 服务器树连接徽标 + 最近错误 | 加快排障 | connecting / connected / host-key / auth-fail |
| 传输队列面板（取消 / 重试） | 大文件传输更可控 | 基于 TransferService + reporter |
| 可选的每服务器命令历史 | 运维记忆 | 仅本地，不含密钥 |
| 明确或实现 lrzsz | 产品表述诚实 | 当前代码仅检测 |

## 再往后 — Agent 能力

| 功能 | 风险 | 所需控制 |
| --- | --- | --- |
| `sftp_delete` / `sftp_rename` | 高 | 始终确认；可选路径 allowlist |
| 只读主机信息工具 | 低 | 固定命令模板、超时、脱敏 |
| 有界 `tail` / `grep` 远程辅助 | 中 | 限制字节 / 行数，禁止任意 shell 拼接 |
| 每服务器 Agent 策略（只读 / cwd allowlist / 命令前缀 allowlist） | 中 | 写入服务器配置 schema |
| Agent 操作审计时间线 | 低 | 本地环缓冲，可导出 |
| 工具清单单一来源生成 | 低 | 避免 package / server / docs 漂移 |
| exec 会话复用池 | 中 | 生命周期 + 主机密钥 + 跳板机需仔细设计 |

## 远期 — 平台深度

| 功能 | 备注 |
| --- | --- |
| 本地 / 远程 / 动态端口转发 | 价值高，复杂度高 |
| 多跳 ProxyJump 链 | 扩展当前单层 `jumpHostId` |
| 递归目录同步策略 | 跳过 / 覆盖 / 重命名 |
| Marketplace 发布 + 签名 CI | 产品化 |
| 可选隐私友好遥测 | 默认关闭 |

## 明确非目标（现阶段）

- 用内置聊天产品替换用户 IDE 里的 Agent。
- 在远端主机常驻 Agent 守护进程（保持无代理）。
- 自动信任已变更的主机密钥。
- 通过资产导出迁移主机信任记录（保持首次连接确认）。
