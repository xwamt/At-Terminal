# 服务巡检文档

当用户需要日检、周检、月检或专项巡检文档时读取本文件。

## 必需结构

1. **巡检信息**：周期、时间、环境、服务、范围和执行人。
2. **基线与判定**：版本、容量、SLO、告警阈值和适用标准。
3. **巡检结果**：逐项记录检查方法、判定标准、实际结果、证据和状态。
4. **异常与风险**：风险等级、影响、处置建议和是否需要升级。
5. **整改计划**：整改建议、责任人、期限和复核方式。
6. **结论**：总体状态、未检查项、不适用项和持续观察事项。

未执行的检查项必须标记为 `未检查`，不能标记为 `正常`。没有统一基线时标记 `待确认`，不得自行发明阈值。抽样检查必须记录样本范围，瞬时结果不得冒充时间段趋势。
